This run implements **Defect 7 remediation item 2** for the first time. That item states a pre-work record must not vouch for itself: the row should name the commit identifier returned by the API call that wrote it, so the claim cannot be written before the fact it asserts. Mechanism used:

The provenance sentence is therefore written *after* the commit it describes, by a separate act, and is checkable by anything that reads the file against the commit log.
